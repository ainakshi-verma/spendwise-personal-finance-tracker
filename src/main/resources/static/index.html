System & Project Details

Server Side Engineering (SSE) academic specifications

Project Name: SpendWise Personal Finance Tracker
Backend Engine: Java 21 / Spring Boot 3.3.5
Database Persistence: MySQL Relational Database (schema: finance_tracker)
ORM Framework: Hibernate JPA with Spring Data Specifications
Monetary Precision: java.math.BigDecimal & SQL DECIMAL(12, 2)
Frontend Architecture: Semantic HTML5, Modular CSS3, Vanilla ES6 JavaScript
Data Visualization: Chart.js (bundled offline)
Automated Tests: JUnit 5, Spring Boot Test, MockMvc (H2 test profile)
